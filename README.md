# Introduction

This repository contains the setup to perform lead optimization with bioisosteres, other modules for a local energy minimization and aligment are available as well.

# Installation

Clone this repository to use it.

```git clone https://github.com/WoutVanEynde/LOSDT.git```

An .exe file is included so no installation is needed, in this case you can just run the executable and it should work.

In case you want to use a conda environment, run:

```
conda env create -f environment.yml
```

# Usage

An .exe file is included so no installation is needed, in this case you can just run the executable and it should work.

In order to run the application with conda, use:

```
conda activate LOSDT

streamlit run Home.py
```
